# Pages

## 1. JSON — Authentication & Engagement Pages

- **Login Screen:** Email/password input and Google OAuth button.
- **Registration Screen:** Form with email, password, and CAPTCHA integration.
- **Account Recovery Screen:** "Forgot Password" email input and confirmation view.
- **Comments Interface (Overlay/Screen):** Interactive UI for viewing and leaving timestamped comments tied to the audio waveform.
- **Engagement Lists Screen:** Reusable list view to display users who liked or reposted a specific track.

## 2. Ziad — Core Audio & Profile Pages

- **Persistent Player Bar (Global Widget):** Sticky audio player that remains at the bottom of the screen during navigation.
- **Full-Screen Player UI:** Expanded view with seek bar and high-fidelity playback controls.
- **User Profile Screen:** Display of avatar, cover photo, dynamic bio, and lists of uploaded tracks/reposts.
- **Edit Profile / Settings Screen:** Form to update visual assets and privacy visibility settings.
- **Listening History Screen:** View showing "Recently Played" tracks.

## 3. Karim — Discovery & Messaging Pages

- **Activity Feed (Home) Screen:** Chronological feed of tracks from followed artists.
- **Global Search Screen:** Input interface with filter tabs for Tracks, Users, and Playlists.
- **Trending & Charts Screen:** Discovery view showing top tracks based on engagement velocity.
- **Chat List Screen:** List of all active 1-to-1 conversations with unread indicators.
- **Direct Message Thread Screen:** Chat interface supporting text and embeddable track/playlist cards.

## 4. Jiljil — Playlists, Notifications & Upload Pages

- **My Playlists Screen:** Grid/list view of all user-created collections.
- **Playlist Builder / Edit Screen:** Drag-and-drop sequencing (`ReorderableListView`) to order tracks and set Secret/Public privacy.
- **Notifications Center Screen:** Chronological list of alerts (Likes, Reposts, Comments, New Followers) with a global "Mark as Read".
- **Track Upload Screen:** Multi-step form for MP3/WAV selection, metadata (title, tags), and public/private toggles.

## 5. Abdalrahman — Social Graph & Subscription Pages

- **Network List Screen:** Reusable list view with tabs for Followers, Following, and Suggested Users.
- **Moderation Settings Screen:** Management view for the "Blocked Users" list.
- **Premium Upgrade (Paywall) Screen:** UI highlighting perks of Pro/Go+ (unlimited uploads, offline listening) with a mock Stripe checkout flow.
